# Godot 2D Platformer

A classic 2D platformer game built with **Godot 4**.

🎮 **[Play the Game on GitHub Pages](https://berkslv.github.io/godot-platformer/)**

---

## 🕹️ Controls

- **Move Left / Right**: `A` / `D` or `Left` / `Right` Arrow Keys
- **Jump**: `Space` or `W` / `Up` Arrow Key

---

## ✨ Features

- Smooth 2D character movement and jump physics
- Animated character states (Idle, Run)
- Moving platforms
- Collectible coins with sound effects
- Enemy hazards and death/respawn mechanics
